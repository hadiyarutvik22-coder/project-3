# 🎓 Student Data Organizer

Welcome to the **Student Data Organizer**! 📚💻

This is a simple Python project for managing student information through a menu-driven program.

## ✨ Features

- ➕ Add Student
- 👀 Display All Students
- ✏️ Update Student Information
- 🗑️ Delete Student
- 📚 Display Subjects Offered
- 🚪 Exit the program

## 🧑‍🎓 Student Information

When adding a student, the program asks for:

- 🆔 Student ID
- 👤 Name
- 🎂 Age
- 🏫 Grade
- 📅 Date of Birth
- 📖 Subjects

The program stores each student in a list using a Python dictionary. Subjects entered with commas are converted into a list. 

## 📚 Subjects Offered

The program includes these offered subjects:

- ➗ Math
- 🔬 Science
- 📖 English
- 🏛️ History
- 🎨 Art

## ▶️ How to Run

1. Install Python 3.
2. Open the file **`project 3.py`** in a Python editor such as IDLE, VS Code, or PyCharm.
3. Run the program.
4. Choose an option from the menu.
5. Enter the requested student information.
